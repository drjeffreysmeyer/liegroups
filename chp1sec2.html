    Section 1.2 Group Actions

    In this section we introduce the theory of topological groups which will later aid us in our study of Lie groups. The prerequesites for this chapter are basic point-set topology and basic group theory, which can be found in Munkres and Dummet and Foote respectively.
    🔗

    Subsection 1.2.1 Group Actions

    Definition 1.2.1.

    Let \(G\) be a group and \(X\) a set. A group action of \(G\) on \(X\) is a set map \(G\times X\to X\) (where the image of \((g,x)\) is written \(gx\)) such that \(ex=x\) and \(g(hx)=(gh)x\text{.}\) We sometimes denote a group action of \(G\) on \(X\) by \(G\curvearrowright X\text{.}\)
    🔗
    🔗

    Exercise 1.2.2.

    Let \(G\) be a group and \(X\) a set. Show that the set of group actions of \(G\) on \(X\) is in bijective correspondence to the set of group homomorphisms \(G\to S_X\) where \(S_X\) is the symmetric group on \(X\text{.}\)
    🔗
    🔗

    Definition 1.2.3.

    Let \(G\curvearrowright X\) be a group action. The action is said to be
    🔗
    1. faithful if \(gx=x\) for all \(x\in X\) implies \(g=e\text{.}\)
      🔗
      🔗
    2. fixed point free if \(gx=x\) for any \(x\in X\) implies that \(g=e\)
      🔗
      🔗
    🔗

    Definition 1.2.4.

    The kernel of an action \(G\curvearrowright X\) is the set \(\{g\in G\mid gx = x\) for all \(x\in X\}\text{.}\)
    🔗
    🔗
    Observe that an action is faithful if and only if the kernal of the action is trivial.
    🔗

    Example 1.2.5.

    Let \(G\) be a group. Then left translation \(G\curvearrowright G\) is a fixed point free action.
    🔗
    🔗

    Example 1.2.6.

    Let \(G\) be a group and \(H\subset G\) be a nontrivial subgroup. Then the action of \(G\) on \(G/H\) is not fixed point free, in particular all of \(H\) stabilizes the coset \(H\text{.}\)
    🔗
    🔗

    Definition 1.2.7.

    Suppose that \(G\curvearrowright X\) and let \(x\in X\text{.}\) Then the stabilizer of \(x\) (or isotropy subgroup at \(x\)) is the set \(G_x:=\{g\in G \ | \ gx=x\}\text{.}\) The orbit of x is the set \(\mc{O}_x:=\{gx\ |\ g\in G\}\text{.}\) An action is said to be transitive if \(\mc{O}_x=X\text{.}\)
    🔗
    🔗

    Lemma 1.2.8.

    Let \(G\curvearrowright X\) be a group action. Then the relation \(x\sim y\) if \(x\) and \(y\) lie in the same orbit is an equivalence relation on \(X\text{.}\) In particular orbits partition \(X\text{.}\)
    🔗
    🔗

    Definition 1.2.9.

    Let \(G\) be a topological group and \(X\) is a topological space. A continuous action of \(G\) on \(X\) is a group action \(G\times X\to X\) which is continuous. Here \(G\times X\) is given the product topology.
    🔗
    🔗
    In this definition, the word continuous may be replaced by smooth, analytic, etc. Observe that any group action is continuous when both \(G\) and \(X\) are endowed with the discrete topologies.
    🔗

    Exercise 1.2.10.

    Let \(G\) be a topological group and \(X\) a topological space. Show that the set of continuous group actions of \(G\) on \(X\) injects but does not surject onto the set of continuous group homomorphisms \(G\to Homeo(X)\) where \(Homeo(X)\) is the is the set of homeomorphisms of \(X\) endowed with the compact-open topology.
    🔗
    🔗

    Example 1.2.11.

    If \(H\subseteq G\) is a closed subgroup, then \(G/H\) is Hausdorff and the left multiplication action
    \begin{equation*} \alpha:G\times G/H\to G/H \qquad (g,kH)\mapsto gkH \end{equation*}
    is continuous. We show why this is true. Let \(\pi: G\to G/H\) be the projection map, and then define the map
    \begin{equation*} p: G\times G\to G\times G/H \qquad (g,k) \mapsto (g,\pi(k))=(g,kH) \end{equation*}
    This is a quotient map, so by the universal property of quotient maps, \(\alpha\) is continuous if and only if \(\alpha\circ p\) is continuous. Hence it suffices to show that \(\alpha\circ p\) is continuous. If \(f: G\times G\to G\) is the group multiplication map, we observe that the following diagram commutes \begin{diagram} G\times G &\rOnto^p & G\times G/H &&& (g,k)&\rMapsto^p &(g,kH) \\ \dTo^f & & \dTo_ \alpha &&& \dMapsto^f& &\dMapsto_ \alpha \\ G &\rOnto^\pi & G/H &&& gk &\rMapsto^\pi &gkH \end{diagram} So \(\alpha\circ p = \pi\circ f\text{,}\) the composition of two continuous maps, and thus \(\alpha\circ p\) continuous.
    🔗
    🔗

    Lemma 1.2.12.

    Let \(G\) be a topological group acting continuously on a topological space \(X\) in which point are closed. Then \(G_x\) is a closed subgroup of \(G\) for each \(x\in X\text{.}\)
    🔗
    🔗

    Proof.
    Suppose \(\mu\colon G\times X\to X\) is the action. Since point are closed, \(\mu^{-1}(x)\) is closed. In the product topology \(G\times\{x\}\subseteq G\times X\) is closed, so that \(G\times\{x\}\cap \mu^{-1}(x)\) is closed in \(G\times X\text{.}\) Clearly this intersection is simply \(G_x\times\{x\}\text{,}\) so that \(G_x\) is closed in \(G\text{.}\)
    🔗
    🔗

    Example 1.2.13.

    Let \(G\curvearrowright X\) be a continuous action. Note that orbits need not be closed in \(X\text{.}\) Consider the continuous action of \(\R_+^\times\) on \(\R\text{.}\) There are three orbits under this action: \(\R_+\text{,}\)\(\{0\}\text{,}\) and \(\R_-\text{.}\)
    🔗
    🔗

    Lemma 1.2.14.

    Let \(G\curvearrowright X\) be a continuous action, and \(x\in X\text{.}\) Consider the natural map \(\varphi\colon G/G_x\to \mc{O}_x\) given by \(gG_x\mapsto gx\text{.}\) This is a continuous bijection.
    🔗
    🔗

    Proof.
    That \(\varphi\) is a bijection is a result of elementary group theory, so we only prove continuity. The projection \(\pi:G\to G/G_x\) is a quotient map, so by the universal property of quotients \(\varphi\) is continuous if and only if \(\varphi\circ \pi\) is continuous. \begin{diagram} G &\rOnto^\pi & G/G_x\\ &\rdTo(2,2)_{\varphi\circ\pi} & \dTo_\varphi\\ & & \mc{O}_x \end{diagram} Now \(\varphi\circ \pi\) is the map \(G\to \mc{O}_x\) given by \(g\mapsto gx\text{,}\) which is continuous by hypothesis.
    🔗
    🔗
    If \(G\) where compact, then \(\varphi\) would be a closed map, and hence a homeomorphism. We can in fact conclude that \(\varphi\) is a homeomorphism under weaker conditions:
    🔗

    Theorem 1.2.15 Baire.

    Let \(X\) be a locally compact Hausdorff space or a complete metric space. Let \(\{A_n\}_{n\in\N}\) be any countable collection of closed sets in X each of whose interior is empty. Then the union \(\bigcup_{n\in\N}A_n\) also has empty interior.
    🔗
    🔗

    Theorem 1.2.16.

    Suppose \(G\) is a locally compact second countable topological group, and \(\mc{O}_x\) is locally compact (or a complete metric space). Then the orbit map \(\varphi\colon G/G_x\to \mc{O}_x\) is a homeomorphism.
    🔗
    🔗
    This is an immediate corollary of the following proposition:
    🔗

    Proposition 1.2.17.

    Let \(G\) act continuously and transitively on \(X\text{.}\) Assume \(G\) is locally compact and second countable, and that \(X\) is locally compact (or a complete metric space). Then for any open set \(U\subseteq G\) and \(x\in X\text{,}\) \(Ux\) is open in \(X\text{.}\)
    🔗
    🔗

    Proof.
    Let \(K\subseteq U\) be a compact subset with nonempty interior. Such a \(K\) exists since \(G\) is locally compact. Because \(G\) is second countable, there exists a sequence \(g_n\in G\) such that \(G = \bigcup_n g_n K\text{.}\) Therefore
    \begin{equation*} X = Gx = \bigcup_n g_nKx. \end{equation*}
    Now each \(g_nKx\) is compact, and hence closed. By the Baire category theorem, not all of the \(g_nKx\) can have nonempty interior. By translation, \(Kx\) has nonempty interior.
    🔗
    Let \(g\in U\text{,}\) so that \(g^{-1}U\) is a neighborhood of \(e\text{.}\) Since \(G\) is locally compact, we have by Proposition Proposition 1.1.8 that there is a symmetric neighborhood \(V\subseteq g^{-1}U\) of \(e\) such that \(\ol{V}\cdot\ol{V}\subseteq g^{-1}U\text{,}\) with \(\ol{V}\) compact. Thus \(g\ol{V}\) is a compact subset of \(U\) such that \(g\ol{V}\cdot \ol{V}\subseteq U\text{.}\) As shown above, \(\ol{V}x\) has nonempty interior. Suppose \(hx\in \Int(\ol{V}x)\text{,}\) for \(h\in\ol{V}\text{.}\) Then \(gh^{-1}hx = gx\in \Int(gh^{-1}\ol{V}x)\text{.}\) But \(g^{-1}h\ol{V}\subseteq U\text{,}\) so that \(gx\in\Int(Ux)\text{.}\) But \(g\) was arbitrary, so \(Ux\) is open.
    🔗
    🔗
    🔗

    Subsection 1.2.2 Linear Group Actions

    In the following section \(V\) shall be a finite dimensional vector space over a topological field \(\F\) (which will usually be \(\R\) or \(\C\)).
    🔗

    Definition 1.2.18.

    Let \(G\) be a group and let \(V\) be a vector space. A linear action of \(G\) on \(V\) is an action \(\mu:G\times V\to V\) such that for each \(g\in G\text{,}\) the map
    \begin{equation*} \mu_g:V\to V\qquad v\to \mu(g,v) \end{equation*}
    is linear.
    🔗
    🔗
    We topologize \(GL(V)\) by choosing a basis for \(V\) and identifying \(GL(V)\cong GL_n(\F)\cong \F^{n^2}\text{.}\)
    🔗

    Lemma 1.2.19.

    The topology on \(GL(V)\) obtained in this way is independent of the basis chosen.
    🔗
    🔗

    Proof.
    The map \(\F^{n^2}\to \F^{n^2}\) induced via conjugation by a fixed matrix in \(GL_n(\F)\) is a homeomorphism.
    🔗
    🔗

    Proposition 1.2.20.

    Let \(G\) be a topological group and let \(V\) be a finite dimensional \(\F\)-vector space. Then the continuity of a linear action \(G\curvearrowright V\) is equivalent to the continuity of the induced homomorphism \(G\to GL(V)\text{.}\)
    🔗
    🔗

    Proposition 1.2.21.

    Given a linear action \(G\curvearrowright V\text{,}\) we get a natural action \(G\curvearrowright V^*\text{,}\) given by \((g\cdot v^*)(w) = v^*(g^{-1}w)\text{.}\) This action is continuous.
    🔗
    🔗

    Definition 1.2.22.

    Let \(G\) be a group and let \(V\) be a vector space. If \(G\curvearrowright V\) is a linear action, \(V\) is said to be a \(G\)-module.
    🔗
    🔗
    If \(V\) and \(W\) are \(G\)-modules, then
    🔗
    1. \(V\oplus W\) is a \(G\)-module under the action \(g(v,w) = (gv,gw)\text{.}\)
      🔗
      🔗
    2. \(V\otimes W\) is a \(G\)-module under the action \(g(v\otimes w) = gv\otimes gw\text{.}\)
      🔗
      🔗
    3. \(\bigwedge^n V\) is a \(G\)-module under the action \(g(v_1\wedge\cdots\wedge v_n) = gv_1\wedge\cdots\wedge gv_n\text{.}\)
      🔗
      🔗

    Definition 1.2.23.

    A \(G\)-module \(V\) is irreducible if there are no vector subspaces \(W\subseteq V\) such that \(GW = W\) other than \(0\) and \(V\text{.}\)
    🔗
    🔗

    Definition 1.2.24.

    A \(G\)-module \(V\) is completely reducible if for any \(G\)-submodule \(W\subseteq V\text{,}\) there exists a complimentary \(G\)-submodule \(W'\subseteq V\) such that \(V=W\oplus W'\text{.}\)
    🔗
    🔗

    Definition 1.2.25.

    Let \(G\) be a group and let \(V\) and \(W\) be \(G\)-modules. A \(G\)-module homomorphism \(f: V\to W\) is a linear map that commutes with the action of \(G\text{,}\) i.e., \(f(gx) = gf(x)\text{.}\)
    🔗
    🔗

    Lemma 1.2.26 Schur.

    Given two irreducible \(G\)-modules \(V\) and \(W\text{,}\) a \(G\)-homomorphism \(V\to W\) is either \(0\) or an isomorphism.
    🔗
    🔗

    Proof.
    Let \(f\colon V\to W\) be a \(G\)-module homomorphism. Then \(f(V)\) and \(\ker f\) are \(G\)-submodules. Since \(f(V)\) is a \(G\)-submodule and \(W\) is irreducible, \(f(V) = 0\) or \(W\text{.}\) If \(f(V) = 0\text{,}\) then \(f\equiv 0\text{.}\) Suppose then that \(f(V) = W\neq 0\text{,}\) so \(f\) is surjective. Since \(f\not\equiv 0\text{,}\) \(\ker f\neq V\text{.}\) But then since \(V\) is irreducible, \(\ker f = 0\text{,}\) so \(f\) is injective.
    🔗
    🔗

    Corollary 1.2.27.

    Given an irreducible \(G\)-module \(V\text{,}\) \(\End_G(V)\) is a division algebra.
    🔗
    🔗

    Proposition 1.2.28.

    Over \(\C\text{,}\) the only finite dimensional division algebra is \(\C\) itself.
    🔗
    🔗

    Proof.
    Suppose that \(D\) is a finite dimensional division algebra over \(\C\text{.}\) Let \(d\in D\text{,}\) and define \(\ell_d\colon D\to D\) by \(\ell_d(x) = dx\text{.}\) Then \(\ell_d\) is a linear map \(D\to D\text{.}\) Since \(\C\) is algebraically closed, \(\ell_d\) must have an eigenvalue \(\lambda\text{.}\) Thus there is an non-zero \(x\in D\) such that \(\ell_d(x) = \lambda x = dx\text{.}\) In particular, \((d - \lambda)x = 0\text{,}\) which is only possible in a division algebra if \(d - \lambda = 0\text{.}\)
    🔗
    🔗

    Corollary 1.2.29.

    If \(M\) is an irreducible \(G\)-module over \(\C\text{,}\) then \(\End_G(M)\cong \C\text{,}\) i.e., all \(G\)-module endomorphisms are just multiplication by scalars.
    🔗
    🔗

    Corollary 1.2.30.

    More generally, if \(M_1\) and \(M_2\) are irreducible \(G\)-modules over \(\C\text{,}\) and \(f,f'\colon M_1\to M_2\) are \(G\)-module isomorphisms, then \(f' = \lambda f\) for some \(\lambda\in \C\text{.}\)
    🔗
    🔗

    Proof.
    Just consider \(f^{-1}\circ f'\in \End_G(M_1)\cong \C\text{.}\)
    🔗
    🔗

    Definition 1.2.31.

    Let \(M\) be a \(G\)-module. A bilinear form \((-,-)\colon M\times M\to \F\) is said to be \(G\)-invariant if for all \(x,y\in M\) and \(g\in G\text{,}\)
    \begin{equation*} (gx, gy) = (x,y). \end{equation*}
    The form is called symmetric if \((x,y) = (y,x)\) for all \(x,y\in M\text{,}\) and called antisymmetric of \((x,y) = -(y,x)\) for all \(x,y\in M\text{.}\)
    🔗
    🔗
    Any (\(G\)-invariant) bilinear form \((-,-)\colon M\times M\to \F\) can be written as the sum of a symmetric and a (\(G\)-invariant) antisymmetric bilinear form:
    \begin{equation*} (x,y) = \frac{1}{2}\left[(x,y) + (y,x)\right] + \frac{1}{2}\left[(x,y) - (y,x)\right]. \end{equation*}
    🔗

    Proposition 1.2.32.

    There is a natural correspondence between bilinear forms on \(M\) and linear maps \(M\to M^*\text{.}\) Under this correspondence, \(G\)-invariant bilinear forms correspond to \(G\)-module homomorphisms.
    🔗
    🔗

    Proof.
    Suppose that \((-,-)\) is a bilinear form on \(M\text{.}\) For each \(x\in M\text{,}\) we get a map \(f_x\in M^*\) given by \(f_x(y) = (x,y)\text{.}\) Conversely, given linear map \(f\colon M\to M^*\text{,}\) the map \(M\times M\to \F\) given by \((x,y) = f(x)(y)\) is a bilinear form. This establishes the correspondence.
    🔗
    Suppose then that \((-,-)\) is a \(G\)-invariant bilinear form on \(M\text{,}\) and let \(f\colon M\to M^*\) be the induced linear map \(x\mapsto f_x\text{.}\) Then
    \begin{equation*} f(gx)(y) = f_{gx}(y) = (gx, y) = (x, g^{-1}y) = f_x(g^{-1}y) = f(x)(g^{-1}y) = [gf(x)](y). \end{equation*}
    Thus \(f(gx) = gf(x)\text{,}\) and \(f\) is a \(G\)-module homomorphism. Conversely, suppose that one is given a \(G\)-module homomorphism \(f\colon M\to M^*\text{,}\) and let \((-,-)\) be the induced bilinear form. Then
    \begin{equation*} (gx,gy) = f(gx)(gy) = [g^{-1}f(gx)](y) = f(g^{-1}gx)(y) = f(x)(y) = (x,y).\qedhere \end{equation*}
    🔗
    🔗

    Proposition 1.2.33.

    If \(M\) is an irreducible \(G\)-module if and only if \(M^*\) is irreducible.
    🔗
    🔗

    Proof.
    First note that \(M\) is naturally isomorphic to \(M^{**}\) as \(G\)-modules via the map \(x\mapsto \delta_x\text{,}\) where \(\delta_x(f) = f(x)\text{.}\) Thus we need only prove one direction of the statement. Suppose that \(M\) is reducible, with \(N\subseteq M\) a non-zero proper \(G\)-submodule. Then we have the exact sequence
    \begin{equation*} 0\longrightarrow N\longrightarrow M. \end{equation*}
    Taking adjoints gives an exact sequence
    \begin{equation*} M^*\longrightarrow N^*\longrightarrow 0. \end{equation*}
    The kernel of the first map in this sequence must be a non-zero proper \(G\)-submodule of \(M^*\text{,}\) so \(M^*\) is reducible.
    🔗
    🔗

    Corollary 1.2.34.

    Suppose that \(M\) is an irreducible \(G\)-module over \(\C\text{.}\) Then there is a \(G\)-invariant bilinear form on \(M\) if and only if \(M\cong M^*\) as \(G\)-modules. In this case, all bilinear forms are the same up to scalar multiple.
    🔗
    🔗

    Definition 1.2.35.

    A representation \(M\) of \(G\) is said to be self-dual if \(M\cong M^*\text{.}\)
    🔗
    🔗

    Corollary 1.2.36.

    Suppose \(M\) is an irreducible \(G\)-module over \(\C\text{.}\) Then \(M\) cannot have both a non-zero symmetric \(G\)-invariant bilinear form and a non-zero antisymmetric \(G\)-invariant bilinear form.
    🔗
    🔗

    Proof.
    This is clear, for any two \(G\)-invariant bilinear forms must be scalar multiples.
    🔗
    🔗

    Theorem 1.2.37.

    Over \(\R\text{,}\) there are only \(3\) associative division algebras, namely \(\R\text{,}\) \(\C\text{,}\) and \(\Ham\text{,}\) where \(\Ham\) is Hamilton’s Quaternions:
    \begin{equation*} \Ham = \R\oplus\R i\oplus\R j\oplus\R k,\,\,\,\,i^2 = j^2 = k^2 = -1,\,\,\,\,ij = k = -ji. \end{equation*}
    In particular, if \(M\) is an irreducible \(G\)-module over \(\R\text{,}\) then \(\End_G(M)\cong \R, \C\) or \(\Ham\text{.}\)

    Subsection 1.2.3 Groups Arising from \(\Ham\)

    Definition 1.2.41.

    If \(x = a_0 +a_1i + a_2j + a_3k\in \Ham\text{,}\) we define the conjugate of \(x\) to be
    \begin{equation*} \ol{x} = a_0 - a_1i - a_2j - a_3k. \end{equation*}
    There is a norm on \(\Ham\text{,}\) define by
    \begin{equation*} \|x\|^2 = x\ol{x} = a_0^2 + a_1^2 + a_2^2 + a_3^2. \end{equation*}
    The norm is multiplicative: \(\|xy\| = \|x\|\|y\|\text{.}\)
    🔗
    🔗
    Because the norm is multiplicative, \(\{x\in \Ham\mid \|x\| = 1\}\) is a subgroup of \(\Ham^\times\text{.}\) Topologically, this subgroup is homeomorphic to \(\mathbb{S}^3\text{,}\) so we will denote this subgroup by \(\mathbb{S}^3\text{.}\)
    🔗
    There is a linear action \(\Sph^3\times \Sph^3\curvearrowright \Ham\) given by
    \begin{equation*} (x,y)\cdot z = xzy^{-1}. \end{equation*}
    The kernel of this action is \(\{(1,1), (-1,-1)\}\text{.}\) Via three homomorphisms \(\varphi_1, \varphi_2, \varphi_3\colon \Sph^3\to \Sph^3\times\Sph^3\text{,}\) we get linear actions \(\Sph^3\curvearrowright \Ham\text{.}\) These homomorphisms are
    \begin{equation*} \varphi_1(x) = (x,1),\,\,\,\,\,\,\varphi_2(x) = (1,x),\,\,\,\,\,\,\varphi_3(x) = (x,x), \end{equation*}
    and result in the actions
    \begin{equation*} x\cdot z = xz,\,\,\,\,\,\, x\cdot z = zx^{-1},\,\,\,\,\,\, x\cdot z = xzx^{-1} \end{equation*}
    respectively. Each of the \(\varphi_i\) are injective, and thus the kernel of each of these actions is \(\varphi_i^{-1}(\{(1,1), (-1,-1)\})\text{.}\) In particular, the first two actions have trivial kernel, and the third has kernel \(\{\pm 1\}\text{.}\) The first two actions result in irreducible representations of \(\Sph^3\text{,}\) as, for instance, they act transitively on the sphere \(\Sph^3\subseteq\Ham\text{.}\) In particular, the original action must also be irreducible. The last action, on the other hand, fixes \(\R\) and the space of pure quaternions \(\Ham_0 = \R i\oplus \R j\oplus \R k\text{,}\) and is thus a reducible representation.
    🔗
    Now each of these representations preserves the norm, so from each of these actions we get homomorphisms \(\Sph^3\to O(\Ham)\cong O_4\text{.}\) As \(\Sph^3\) is connected, this (continuous) homomorphism must map into the connected component of the identity, i.e., we actually get homomorphisms \(\Sph^3\to SO_4\text{.}\) In the case of the last (conjugation) action, looking at the reduced representation of \(\Sph^3\) on \(\Ham_0\) gives a homomorphism \(\Sph^3\to SO(\Ham_0)\cong SO_3\text{.}\) We will see later from topological considerations that this map must be surjective. Hence by the first isomorphism theorem, \(\Sph^3/\{\pm 1\}\cong SO_3\text{.}\) As one might expect from this \(SO_3\cong \R P^3\text{.}\)
    🔗
    Note that if we view \(\C\) as the subspace \(\R\oplus \R i\subseteq\Ham\text{,}\) the the left multiplication action is \(\C\)-linear, and hence induces a homomorphism \(\Sph^3\to U_2\text{.}\) This will turn out to be an isomorphism \(\Sph^3\to SU_2\text{.}\)
