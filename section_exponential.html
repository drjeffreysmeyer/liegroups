    Section 1.3 Exponential Map

    In this section we introduce exponential map. We start with understanding the exponential map for matrices, extract its properties and then construct and analyze the formal object.
    🔗

    Subsection 1.3.1 The Exponential Matrix

    In this subsection we introduce the exponential matrix. We will focus on the case of 2 by 2 matrices, but the results generalize to n by n matrices.
    🔗

    Proposition 1.3.1.

    If \(g\in \GL_2(\R)\) and \(L_g:G\to G\) is the left translation by \(g\text{,}\) then
    \begin{equation*} dL_g: T_IG \to T_gG \end{equation*}
    where \(dL_g(A)=gA\text{.}\)
    🔗
    🔗

    Hint.
    Look at the curve \(c(t) = (I+tA)\) and look at the tangent vector at \(t=0\) to the translated curve \(L_g(c(t))\text{.}\)
    🔗

    Definition 1.3.2 Integral Curve.

    If \(M\) is a smooth manifold and \(X\in \mathfrak{X}(M)\) is a smooth vector field, then a smooth curve \(c:I\to M\) is an integral curve of \(X\) if \(c'(t) = X_{c(t)}\) for all \(t\in I\text{.}\)
    🔗
    🔗
    If \(A\in \Mat_2(\R)\text{,}\) then observe that an integral curve to the left-invariant vector field
    \begin{equation*} X_A(g) = gA \end{equation*}
    must satisfy the equation
    \begin{equation*} c'(t) = (c(t))A\text{.} \end{equation*}
    This suggests from calculus that an integral curve should be an exponential function. But how dow we make send of that for matrices? Let’s start with the formal power series:
    🔗
    \begin{equation*} e^A := I + A + \frac{1}{2}A^2 + \frac{1}{6}A^3 + \cdots + \frac{1}{n!}A^n + \cdots \end{equation*}
    But doe this converge to a matrix?
    🔗

    Definition 1.3.3 Frobenius Norm.

    The Frobenius norm of a matrix \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix}\) is defined as
    \begin{equation*} \|A\|_F = \sqrt{a^2 + b^2 + c^2 + d^2} \end{equation*}
    🔗
    🔗
    The Frobenius norm on matrices is just the standard Euclidean norm on the space of matrices when identified with \(\R^{4}\text{.}\) It immediately follows that it is positive definite, symmetric, bilinear, and moreover it induces the standard topology on the space of matrices.
    🔗

    Proposition 1.3.4 The Frobenius Norm is Submultiplicative.

    If \(A,B\in \mf{gl}_2(\R)\) then \(\|AB\|_F \leq \|A\|_F\|B\|_F\text{.}\)
    🔗
    🔗

    Proof.
    Let \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix}\) and \(B = \begin{bmatrix} e \amp f\\g \amp h\end{bmatrix}\text{.}\) Then
    \begin{equation*} AB = \begin{bmatrix} ae+bg \amp af+bh\\ce+dg \amp cf+dh\end{bmatrix} \end{equation*}
    so that
    \begin{equation*} \|AB\|_F^2 = (ae+bg)^2 + (af+bh)^2 + (ce+dg)^2 + (cf+dh)^2 \end{equation*}
    Using the Cauchy-Schwarz inequality twice and summing, we have
    \begin{align*} (ae+bg)^2 + (af+bh)^2 \amp \leq (a^2+b^2)(e^2+f^2) + (a^2+b^2)(g^2+h^2) \\ \amp = (a^2+b^2)(e^2+f^2+g^2+h^2) \end{align*}
    and similarly
    \begin{align*} (ce+dg)^2 + (cf+dh)^2 \amp \leq (c^2+d^2)(e^2+f^2) + (c^2+d^2)(g^2+h^2) \\ \amp = (c^2+d^2)(e^2+f^2+g^2+h^2) \end{align*}
    Adding these two inequalities gives
    \begin{equation*} \|AB\|_F^2 \leq (a^2+b^2+c^2+d^2)(e^2+f^2+g^2+h^2) = \|A\|_F^2\|B\|_F^2 \end{equation*}
    Taking square roots gives the desired result.
    🔗
    🔗

    Proposition 1.3.5.

    If \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix} \in \mf{gl}_2(\R)\) then the series
    \begin{equation*} e^A = I + A + \frac{1}{2}A^2 + \frac{1}{6}A^3 + \cdots + \frac{1}{n!}A^n + \cdots \end{equation*}
    is absolutely convergent relative to the Frobenius norm.
    🔗
    🔗

    Proof.
    Let \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix} \in \mf{gl}_2(\R)\text{.}\) Then
    \begin{equation*} \|e^A\|_F = \|I + A + \frac{1}{2}A^2 + \frac{1}{6}A^3 + \cdots + \frac{1}{n!}A^n + \cdots\|_F \end{equation*}
    By the triangle inequality and submultiplicativity of the Frobenius norm, we have
    \begin{equation*} \|e^A\|_F \leq 1 + \|A\|_F + \frac{1}{2}\|A\|_F^2 + \frac{1}{6}\|A\|_F^3 + \cdots + \frac{1}{n!}\|A\|_F^n + \cdots = e^{\|A\|_F} \end{equation*}
    which is finite. Hence the series converges absolutely.
    🔗
    🔗

    Definition 1.3.6 Exponential Matrix.

    If \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix} \in \mf{gl}_2(\R)\text{,}\) then its exponential matrix is the matrix
    \begin{equation*} e^A = I + A + \frac{1}{2}A^2 + \frac{1}{6}A^3 + \cdots + \frac{1}{n!}A^n + \cdots \end{equation*}
    🔗
    🔗

    Proposition 1.3.7.

    If \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix} \in \mf{gl}_2(\R)\) and \(A=PBP^{-1}\) for some invertible matrix \(P\text{,}\) then \(e^A = Pe^BP^{-1}\text{.}\)
    🔗
    🔗

    Example 1.3.8.

    It is good to know the exponential of some simple matrices explicitly.
    🔗
    If \(D = \begin{bmatrix} a \amp 0\\0 \amp d\end{bmatrix}\text{,}\) then \(e^D = \begin{bmatrix} e^a \amp 0\\0 \amp e^d\end{bmatrix}\)
    🔗
    If \(T = \begin{bmatrix} 0 \amp b\\0 \amp 0\end{bmatrix}\text{,}\) then \(e^T = \begin{bmatrix} 1 \amp b\\0 \amp 1\end{bmatrix}\)
    🔗
    If \(R = \begin{bmatrix} 0 \amp -t\\t \amp 0\end{bmatrix}\text{,}\) then \(e^R = \begin{bmatrix} \cos(t) \amp -\sin(t)\\\sin(t) \amp \cos(t)\end{bmatrix}\)
    🔗
    🔗

    Proposition 1.3.9.

    If \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix} \in \mf{gl}_2(\R)\) then \(\det(e^A) = e^{\tr(A)}\text{.}\)
    🔗
    🔗
    This result has several important implications. First, the exponential matrix is always invertible, since \(e^{\tr(A)}\neq 0\text{.}\) In other words, if \(A\in \mf{gl}_2(\R)\text{,}\) then \(e^A\in \GL_2(\R)\text{.}\) Second, we may restrict the exponential matrix to the Lie subalgebra \(\mf{sl}_2(\R)\) of matrices with zero trace. The restriction of the exponential map to \(\mf{sl}_2(\R)\) has image in \(\SL_2(\R)\text{,}\) the space of matrices with determinant one.
    🔗
    Food for thought - can you find a matrix \(A\in \mf{gl}_2(\R)\) such that \(e^A = I\) but \(A\neq 0\text{?}\) Can you find a matrix \(A\in \mf{gl}_2(\R)\) such that \(e^A = -I\text{?}\)
    🔗

    Proposition 1.3.10.

    If \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix} \in \mf{gl}_2(\R)\) and \(t\in \R\text{,}\) then \(\gamma(t)=e^{tA}\) is a smooth curve in \(\GL_2(\R)\) such that \(\gamma(0) = I\) and \(\gamma'(0) = A\text{.}\)
    🔗
    🔗

    Proof.
    Let \(A = \begin{bmatrix} a \amp b\\c \amp d\end{bmatrix} \in \mf{gl}_2(\R)\) and \(t\in \R\text{.}\) Then
    \begin{equation*} \gamma(t) = e^{tA} = I + tA + \frac{1}{2}t^2A^2 + \frac{1}{6}t^3A^3 + \cdots + \frac{1}{n!}t^nA^n + \cdots \end{equation*}
    is a smooth curve in \(\GL_2(\R)\) since the series converges absolutely. We have
    \begin{equation*} \gamma(0) = e^{0\cdot A} = I \end{equation*}
    and
    \begin{equation*} \gamma'(t) = A + tA^2 + \frac{1}{2}t^2A^3 + \cdots + \frac{1}{(n-1)!}t^{n-1}A^n + \cdots \end{equation*}
    so that
    \begin{equation*} \gamma'(0) = A \end{equation*}
    🔗
    🔗

    Proposition 1.3.11 Baker-Campbell-Hausdorff Formula.

    If \(A,B \in \mf{gl}_2(\R)\text{,}\) then \(e^A e^B = e^{C}\) where \(C\) is a series in the brackets of \(A\) and \(B\text{:}\)
    \begin{equation*} C = A + B + \frac{1}{2}[A,B] + \frac{1}{12}([A,[A,B]] + [B,[B,A]]) - \frac{1}{24}[B,[A,[A,B]]] + \cdots \end{equation*}
    🔗
    🔗
    🔗

    Subsection 1.3.2 The Exponential Map

    Motivated by the intuition from the exponential matrix, in this subsection we introduce the exponential map for formal Lie groups.
    🔗

    Blackbox Theorem 1.3.12 There exists unique maximal integral curves.

    If \(M\) is a smooth manifold, \(p\in M\text{,}\) and \(X\in \mathfrak{X}(M)\) is a smooth vector field, then there exists a unique smooth curve \(c_X(t):(a,b)\to M\) such that
    1. (Based at p) \(a < 0 < b\) and \(c_X(0) = p\)
      🔗
      🔗
    2. (Integral) \(c_X'(t) = X_{c_X(t)}\) for all \(t\in (a,b)\)
      🔗
      🔗
    3. (Maximal) If \(\tilde{c}:(\tilde{a},\tilde{b})\to M\) is another integral curve with \(\tilde{c}(0) = p\text{,}\) then \((\tilde{a},\tilde{b}) \subset (a,b)\) and \(\tilde{c}(t) = c_X(t)\) for all \(t\in (\tilde{a},\tilde{b})\text{.}\)
      🔗
      🔗
    🔗
    🔗
    The proof of this theorem is a direct application of the existence and uniqueness theorem for ordinary differential equations.
    🔗
    If \(X\in L(G)\) is a left-invariant vector field on a Lie group \(G\text{,}\) then we denote its unique maximal integral curve based at the identity by \(c_X(t)\text{.}\)
    🔗
    While we will not have explicit formulas for these integral curves of left-invariant vector fields, we will leverage the existence, uniqueness, and maximality to define and prove general properties of these integral curves.
    🔗
    It is valuable to observe that
    1. If \(X\in L(G)\) and \(g\in G\text{,}\) then \(L_g(c_X(t))\) is an integral curve based at \(g\text{.}\)
      🔗
      🔗
    2. If \(X\in L(G)\) and \(s\in \R\text{,}\) then \(c(t-s)\) is an integral curve based at \(c(-s)\text{.}\)
      🔗
      🔗
    🔗

    Proposition 1.3.13 Integral curves of left-invariant vector fields are complete.

    If \(G\) is a Lie group and \(X\in L(G)\text{,}\) then the domain of the integral curve is \(\R\text{.}\)
    🔗
    🔗

    Proposition 1.3.14 Integral curves of left-invariant vector fields are homomorphisms.

    If \(G\) is a Lie group, \(X\in L(G)\text{,}\) and \(s,t\in \R\text{,}\) then \(c_X(s+t) = c_X(s)c_X(t)\text{.}\)
    🔗
    🔗
    We are therefore justified in referring to the curves \(c_X(t)\) as one-parameter subgroups of the Lie group \(G\text{.}\)
    🔗
    We define the set map
    🔗
    \begin{equation*} \exp: \mathfrak{g} \to G \end{equation*}
    by
    🔗
    \begin{equation*} \exp(X) = c_X(1). \end{equation*}
    It is immediate from the definition that \(\exp(0) = e\) and that \(\exp(tX) = c_X(t)\) for all \(t\in \R\text{.}\)
    🔗

    Proposition 1.3.15 The exponential map is smooth.

    If \(G\) is a Lie group with Lie algebra \(\mathfrak{g}\text{,}\) then the exponential map is smooth.
    🔗
    🔗

    Hint.
    We know the exponential map is smooth along the an integral curve for a fixed left-invariant vector field. Need to show it is smooth as we vary the left-invariant vector field.
    🔗
    🔗

    Proposition 1.3.16 The differential of the exponential map is the identity.

    If \(G\) is a Lie group with Lie algebra \(\mathfrak{g}\text{,}\) then \(d\exp_0\) is the identity map.
    🔗
    🔗

    Hint.
    🔗
    🔗

    Proposition 1.3.17 The exponential map is a local diffeomorphism.

    If \(G\) is a Lie group with Lie algebra \(\mathfrak{g}\text{,}\) the exponential map is a local diffeomorphism at the identity.
    🔗
    🔗

    Hint.
    Use the inverse function theorem.
    🔗
    🔗

    Proposition 1.3.18.

    If \(f:G\to G'\) is an smooth homomorphism of Lie groups and \(X \in L(G)\text{,}\) then
    \begin{equation*} f(\exp(X)) = \exp(df(X)). \end{equation*}
    In other words, the following diagram commutes:
    \begin{equation*} \begin{CD} L(G) @>df>>L(G') \\ @V{\exp}VV @VV{\exp}V \\ G @>>{f}> G' \end{CD} \end{equation*}
    🔗
    🔗
    Typically the best charts on a Lie group are the exponential charts. In particular, if \(G\) is a Lie group with Lie algebra \(\mathfrak{g}\text{,}\) then there exists an open neighborhood \(U\subset \mathfrak{g}\) of the origin and an open neighborhood \(V\subset G\) of the identity such that \(\exp: U \to V\) is a diffeomorphism.
    🔗
    Questions: When is the exponential map surjective? When is it injective? When is it bijective? When is it a diffeomorphism?
    🔗

    Proposition 1.3.19 Differential of the multiplication map is addition.

    If \(G\) is a Lie group and \(\mu:G\times G \to G\) is the multiplication map, then \(d\mu_{(e,e)}:T_eG \times T_eG \to T_eG\) is given by addition, i.e. \(d\mu_{(e,e)}(X,Y) = X+Y\text{.}\)
    🔗
    🔗
    While the exponential map is not a homomorphism, it is a homomorphism to first order.
    🔗

    Proposition 1.3.20 Exponentiation is a “first order” homomorphism.

    If \(G\) is a Lie group, \(t\in \mathbb{R}\text{,}\) and \(X,Y\in L(G)\text{,}\) then \(\exp(tX)\exp(tY) = \exp(X+Y+O(t^2))\) where \(O(t^2)\) is an \(L(G)\)-valued function such that \(\frac{1}{t^2}O(t^2)\) is bounded at \(t=0\text{.}\)
    🔗
    🔗
    This is the start of a more general result known as the Baker-Campbell-Hausdorff formula, which gives an explicit formula for \(O(t^2)\) in terms of brackets of \(X\) and \(Y\text{.}\)
