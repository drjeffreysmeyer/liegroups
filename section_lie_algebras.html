    Section 1.2 Lie Algebras

    In this section we introduce Lie algebras. We start with understanding the matrix Lie algebras, extract their properties and then construct and analyze the formal object.
    🔗

    Subsection 1.2.1 Manifolds

    Definition 1.2.1 Topological Manifold.

    A topological manifold of dimension \(n\) is a topological space \(M\) that is Hausdorff, second-countable, and locally homeomorphic to \(\mathbb{R}^n\text{.}\)
    🔗
    🔗

    Definition 1.2.2 Smooth Manifold.

    A smooth structure on a topological manifold \(M\) is an equivalence class of atlases, where two atlases are equivalent if their union is a smooth atlas. A smooth manifold is a topological manifold equipped with a smooth structure.
    🔗
    🔗

    Definition 1.2.3 Smooth Map.

    Let \(M\) and \(N\) be smooth manifolds. A map \(f:M\to N\) is smooth if for every chart \((U,\phi)\) on \(M\) and every chart \((V,\psi)\) on \(N\text{,}\) the map
    \begin{equation*} \psi \circ f \circ \phi^{-1}:\phi(U\cap f^{-1}(V))\to \psi(V) \end{equation*}
    is smooth in the usual sense.
    🔗
    🔗

    Definition 1.2.4 Smooth Functions.

    Let \(M\) be a smooth manifold. A function \(f:M\to \mathbb{R}\) is smooth if for every chart \((U,\phi)\) on \(M\text{,}\) the map
    \begin{equation*} f \circ \phi^{-1}:\phi(U)\to \mathbb{R} \end{equation*}
    is smooth in the usual sense. We denote the space of all smooth functions on \(M\) by \(C^\infty(M)\text{.}\)
    🔗
    🔗

    Proposition 1.2.5 Smooth Functions Form a Commutative Algebra.

    Let \(M\) be a smooth manifold. Then \(C^\infty(M)\) is a commutative algebra over \(\mathbb{R}\text{.}\)
    🔗
    🔗
    🔗

    Subsection 1.2.2 Tangent Spaces

    Definition 1.2.6 Smooth Curve.

    A smooth curve in a smooth manifold \(M\) is a smooth map \(\gamma:\mathbb{R}\to M\text{.}\)
    🔗
    🔗

    Definition 1.2.7 Tangential Curves.

    Two smooth curves \(c_1\) and \(c_2\) in a smooth manifold \(M\) are tangential at a point \(p\) if for all smooth functions \(f\) defined in a neighborhood of \(p\text{,}\) the derivatives \((f \circ c_1)'(0)\) and \((f \circ c_2)'(0)\) are equal.
    🔗
    If two smooth curves \(c_1\) and \(c_2\) in a smooth manifold \(M\) are tangential at a point \(p \in M\text{,}\) we write \(c_1 \sim c_2\text{.}\)
    🔗
    🔗

    Proposition 1.2.8 Tangential Curves is an Equivalence Relation.

    Let \(M\) be a smooth manifold and let \(p \in M\text{.}\) Then the relation of being tangential at \(p\) is an equivalence relation on the set of smooth curves in \(M\) that pass through \(p\text{.}\)
    🔗
    🔗
    We denote the equivalence class of a smooth curve \(c\) in a smooth manifold \(M\) that passes through a point \(p \in M\) by \([c]\text{.}\)
    🔗

    Definition 1.2.9 Tangent Vector.

    A tangent vector at a point \(p\) in a smooth manifold \(M\) is an equivalence class of smooth curves in \(M\) that are tangential at \(p\text{.}\)
    🔗
    🔗

    Definition 1.2.10 Tangent Space.

    The tangent space of a smooth manifold \(M\) at a point \(p \in M\text{,}\) denoted \(T_pM\text{,}\) is the set of equivalence classes of smooth curves in \(M\) that are tangential at \(p\text{.}\)
    🔗
    🔗

    Proposition 1.2.11 Tangent Space is a Vector Space.

    If \(M\) is a smooth manifold and \(p \in M\text{,}\) then the tangent space \(T_pM\) is a vector space over \(\mathbb{R}\text{.}\)
    🔗
    🔗

    Definition 1.2.12 Tangent Bundle.

    The tangent bundle of a smooth manifold \(M\text{,}\) denoted \(TM\text{,}\) is the disjoint union of all tangent spaces at each point in \(M\text{.}\) In symbols, \(TM = \bigsqcup_{p \in M} T_pM\text{.}\) There is a natural projection map \(\pi:TM\to M\) that sends each tangent vector to the point in \(M\) at which it is tangent.
    🔗
    🔗
    🔗

    Subsection 1.2.3 Differential Maps

    Definition 1.2.13 Differential Map.

    If \(f:M\to N\) is a smooth map of smooth manifolds and \(p \in M\text{,}\) then the maps
    \begin{equation*} df_p:T_pM\to T_{f(p)}N \end{equation*}
    defined by
    \begin{equation*} df_p([c]) = [f \circ c] \end{equation*}
    is called the differential of \(f\) at \(p\text{.}\)
    🔗
    🔗

    Proposition 1.2.14 Differential Map is Well Defined.

    If \(f:M\to N\) is a smooth map of smooth manifolds and \(p \in M\text{,}\) then the differential map
    \begin{equation*} df_p:T_pM\to T_{f(p)}N \end{equation*}
    is well defined.
    🔗
    🔗
    In the case where \(f:M\to \R\) is a smooth function on \(M\) and \(p \in M\text{,}\) then the differential map
    \begin{equation*} df_p:T_pM\to T_{f(p)}\R \cong \R \end{equation*}
    if precisely the standard single variable derivative
    \begin{equation*} df_p([c]) = \frac{d}{dt}[f \circ c](0). \end{equation*}
    In this case, we call \(df_p\) the directional derivative of \(f\) at \(p\text{.}\)
    🔗

    Proposition 1.2.15 Differential Map is Linear.

    If \(f:M\to N\) is a smooth map of smooth manifolds and \(p \in M\text{,}\) then the differential map
    \begin{equation*} df_p:T_pM\to T_{f(p)}N \end{equation*}
    is linear.
    🔗
    🔗
    🔗

    Subsection 1.2.4 Vector Fields

    Let \(M\) be a smooth manifold. Let \(C^\infty(M)\) denote the space of smooth functions on \(M\text{.}\) A vector field on \(M\) is a smooth assignment of a tangent vector to each point of \(M\text{.}\) In other words, a vector field is a smooth map \(X:M\to TM\) such that \(\pi\circ X=\mathrm{id}_M\text{,}\) where \(\pi:TM\to M\) is the canonical projection. The space of all vector fields on \(M\) is denoted by \(\mathfrak{X}(M)\text{.}\)
    🔗

    Definition 1.2.16 Vector Field.

    If \(M\) is a smooth manifold, then a vector field on \(M\) is a smooth assignment of a tangent vector to each point of \(M\text{.}\) More precisely, if \(\pi:TM\to M\) is the tangent bundle, then a vector field is a smooth map \(X:M\to TM\) such that \(\pi\circ X=\mathrm{id}_M\text{.}\)
    🔗
    🔗

    Definition 1.2.17 Directional Derivative.

    If \(M\) is a smooth manifold and \(X \in \mathfrak{X}(M)\text{,}\) then the directional derivative \(D_X\) is a linear map from \(C^\infty(M)\) to \(C^\infty(M)\) defined by
    \begin{equation*} D_X(f)(p) = df_p(X_p). \end{equation*}
    🔗
    🔗
    By abuse of notation, we will often write \(X(f)\) instead of \(D_X(f)\) for the directional derivative associated to \(X\text{.}\)
    🔗

    Proposition 1.2.18 Directional Derivative Satisfy Leibniz Rule.

    If \(X \in \mathfrak{X}(M)\text{,}\) then the directional derivative \(D_X:C^\infty(M)\to C^\infty(M)\) satisfies the Leibniz rule:
    \begin{equation*} D_X(fg) = D_X(f)g + fD_X(g) \end{equation*}
    for all \(f,g \in C^\infty(M)\text{.}\)
    🔗
    🔗

    Hint.
    This is a direct proof. You may find Definition 1.2.13 and Definition 1.2.17 and useful.
    🔗
    🔗

    Definition 1.2.19 Derivation.

    A derivation on a commutative algebra \(A\) is a linear map \(D:A \to A\) that satisfies the Leibniz rule:
    \begin{equation*} D(ab) = D(a)b + aD(b) \end{equation*}
    for all \(a,b \in A\text{.}\) Let \(\mathrm{Der}(A)\) denote the space of all derivations on \(A\text{.}\)
    🔗
    🔗

    Proposition 1.2.20 Vector Field and Derivations are Isomorphic.

    If \(M\) is a smooth manifold, then the map
    \begin{equation*} D: \mathfrak{X}(M) \to \mathrm{Der}(C^\infty(M)) \end{equation*}
    defined by
    \begin{equation*} D(X) = D_X \end{equation*}
    is an isomorphism of vector spaces.
    🔗
    🔗

    Proof.
    🔗

    Definition 1.2.21 Lie Bracket of Derivations.

    If \(M\) is a smooth manifold and \(D_1, D_2 \in \mathrm{Der}(C^\infty(M))\text{,}\) then the Lie bracket of \(D_1\) and \(D_2\) is the map \([D_1,D_2]:C^\infty(M)\to C^\infty(M)\) defined by defined by
    \begin{equation*} [D_1,D_2](f) = D_1(D_2(f)) - D_2(D_1(f)) \end{equation*}
    for all \(f \in C^\infty(M)\text{.}\)
    🔗
    🔗

    Proposition 1.2.22 The Lie Bracket of Derivations is a Derivation.

    If \(M\) is a smooth manifold and \(D_1, D_2\in \mathrm{Der}(C^\infty(M))\text{,}\) then the Lie bracket \([D_1,D_2]\) is also a derivation.
    🔗
    🔗

    Proof.
    This is a direct proof following definitions. Let \(f,g \in C^\infty(M)\text{.}\) First check
    \begin{align*} [D_1,D_2](fg) \amp = D_1(D_2(fg)) - D_2(D_1(fg)) \\ \amp = D_1(D_2(f)g + fD_2(g)) - D_2(D_1(f)g + fD_1(g)). \end{align*}
    Expanding this expression and using the Leibniz rule for \(D_1\) and \(D_2\text{,}\) we obtain
    \begin{align*} [D_1,D_2](fg) \amp= D_1(D_2(f))g + D_2(f)D_1(g) + D_1(f)D_2(g) + fD_1(D_2(g)) \\ \amp - D_2(D_1(f))g - D_1(f)D_2(g) - D_2(f)D_1(g) - fD_2(D_1(g)). \end{align*}
    Simplifying, we find that
    \begin{align*} [D_1,D_2](fg)\amp= (D_1(D_2(f)) - D_2(D_1(f)))g + f(D_1(D_2(g)) - D_2(D_1(g))) \\ \amp= [D_1,D_2](f)g + f[D_1,D_2](g). \end{align*}
    Thus the Lie bracket \([D_1,D_2]\) satisfies the Leibniz rule, and hence is a derivation.
    🔗
    🔗

    Proposition 1.2.23 The Lie Bracket of Derivations Satisfies the Jacobi Identity.

    If \(M\) is a smooth manifold and \(D_1, D_2, D_3 \in \mathrm{Der}(C^\infty(M))\text{,}\) then the Lie bracket
    \begin{equation*} [D_1,[D_2,D_3]] + [D_2,[D_3,D_1]] + [D_3,[D_1,D_2]] = 0. \end{equation*}
    This is known as the Jacobi identity.
    🔗
    🔗

    Proof.
    This is a direct proof following definitions. We expand each term, with adjacent derivations denoting composition.
    \begin{align*} [D_1,[D_2,D_3]] \amp = D_1[D_2,D_3] - [D_2,D_3] D_1 \\ \amp =D_1 D_2 D_3 - D_1 D_3 D_2 - D_2 D_3 D_1 + D_3 D_2 D_1 \\ [D_2,[D_3,D_1]] \amp = D_2[D_3,D_1] - [D_3,D_1] D_2 \\ \amp =D_2 D_3 D_1 - D_2 D_1 D_3 - D_3 D_1 D_2 + D_1 D_3 D_2 \\ [D_3,[D_1,D_2]] \amp = D_3[D_1,D_2] - [D_1,D_2] D_3 \\ \amp =D_3 D_1 D_2 - D_3 D_2 D_1 - D_1 D_2 D_3 + D_2 D_1 D_3 \end{align*}
    Adding these three expressions, we find that all terms cancel, and we obtain the Jacobi identity.
    🔗
    🔗
    Via the isomorphism Proposition 1.2.20, we can define a Lie bracket on the space of vector fields \(\mathfrak{X}(M)\) by defining
    \begin{equation*} [X,Y] = D^{-1}([D(X),D(Y)]) \end{equation*}
    for all \(X,Y \in \mathfrak{X}(M)\text{.}\) In other words, the Lie bracket of vector fields is defined by the commutator of the associated directional derivatives. In the remainder of the book, as is common in the field, we will omit the isomorphism and just often write
    \begin{equation*} [X,Y](f) = X(Y(f)) - Y(X(f)) \end{equation*}
    for the Lie bracket of vector fields.
    🔗

    Definition 1.2.24 Lie Algebra.

    A vector space \(\mathfrak{g}\) is a Lie algebra if it is equipped with a bilinear map
    \begin{equation*} [ , ]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g} \end{equation*}
    called the Lie bracket that satisfies the following properties:
    1. Antisymmetry:
      \begin{equation*} [X,Y] = -[Y,X] \end{equation*}
      for all \(X,Y \in \mathfrak{g}\text{.}\)
      🔗
    2. Jacobi Identity:
      \begin{equation*} [X,[Y,Z]] + [Y,[Z,X]] + [Z,[X,Y]] = 0 \end{equation*}
      for all \(X,Y,Z \in \mathfrak{g}\text{.}\)
      🔗
    🔗
    🔗

    Proposition 1.2.25.

    If \(M\) is a smooth manifold, then the space of vector fields \(\mathfrak{X}(M)\) is a Lie algebra with respect to the Lie bracket defined by
    \begin{equation*} [X,Y](f) = X(Y(f)) - Y(X(f)) \end{equation*}
    for all \(X,Y \in \mathfrak{X}(M)\) and \(f \in C^\infty(M)\text{.}\)
    🔗
    🔗

    Definition 1.2.26 Lie Algebra Homomorphism.

    A linear map \(T: \mathfrak{g} \to \mathfrak{h}\) between Lie algebras is a Lie algebra homomorphism if it preserves the Lie bracket, i.e.,
    \begin{equation*} T([X,Y]) = [T(X),T(Y)] \end{equation*}
    for all \(X,Y \in \mathfrak{g}\text{.}\)
    🔗
    🔗

    Definition 1.2.27 \(f\)-Related Vector Fields.

    If \(f: M \to N\) is a smooth map between smooth manifolds, and \(X \in \mathfrak{X}(M)\) and \(Y \in \mathfrak{X}(N)\) are vector fields, we say that \(X\) and \(Y\) are \(f\)-related if for all \(p \in M\text{,}\) we have
    \begin{equation*} df_p(X_p) = Y_{f(p)}. \end{equation*}
    🔗
    🔗

    Proposition 1.2.28.

    If \(f: M \to N\) is a smooth map between smooth manifolds and with and \(X_1, X_2 \in \mathfrak{X}(M)\) and \(Y_1,Y_2 \in \mathfrak{X}(N)\) are vector fields such that \(X_1\) and \(Y_1\) are \(f\)-related and \(X_2\) and \(Y_2\) are \(f\)-related, then \([X_1,X_2]\) and \([Y_1,Y_2]\) are \(f\)-related.
    🔗
    🔗

    Proof.

    Subsection 1.2.5 Left-Invariant Vector Fields

    We now return to Lie groups.
    🔗

    Definition 1.2.29 Left Invariant Vector Field.

    A left invariant vector field on a Lie group \(G\) is a vector field \(X\) such that for all \(g,h \in G\text{,}\) we have
    \begin{equation*} dL_g (X_h) = X_{gh}, \end{equation*}
    where \(L_g\) is the left translation by \(g\text{.}\)
    🔗
    🔗

    Proposition 1.2.30.

    If \(G\) is a Lie group, then the set \(L(G)\) of left invariant vector fields on \(G\) is a Lie subalgebra of \(\mathfrak{X}(G)\) under the Lie bracket of vector fields.
    🔗
    🔗

    Definition 1.2.31 Lie Algebra of a Lie Group.

    The Lie algebra of a Lie group \(G\text{,}\) which we will denote by \(L(G)\text{,}\) is the set of left-invariant vector fields on \(G\text{,}\) equipped with a bracket operation [ , ] that makes it a Lie algebra.
    🔗
    🔗

    Proposition 1.2.32.

    The Lie algebra of a Lie group \(G\) is isomorphic as a vector space to the tangent space \(T_eG\) at the identity element \(e\text{.}\)
    🔗
    🔗

    Proposition 1.2.33.

    If \(f: G \to G'\) is a Lie group homomorphism, then \(df: L(G) \to L(G')\) is a Lie algebra homomorphism.
    🔗
    🔗

    Proposition 1.2.34 Lie algebra isomorphism implies local diffeomorphism.

    If \(f: G \to G'\) is a Lie group homomorphism and \(df: L(G) \to L(G')\) is an isomorphism, then \(f\) is a local diffeomorphism.
